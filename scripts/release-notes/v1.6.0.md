## v1.6.0 (29)

### 网络页全新版式
- 启动/停止按钮从底部控制卡中移出，改为屏幕正中的大圆电源按钮（PowerOrb），点击热区覆盖整圆
- 底部改为固定双区：左侧「当前网络」卡展示名称、IP，运行时追加设备名；右侧「创建网络 / 导入配置」两张小卡
- 左卡整卡可点击，直接打开「切换网络」面板；网络列表从主页收起，移入面板（单选 + 行尾编辑入口），面板打开时自动刷新配置，替代原先的下拉刷新
- 空态与导入结果弹窗等既有流程保持原样

### 电源按钮动画
- 外圈：底环 + 扫掠渐变弧 + 径向呼吸光晕。空闲时弧静止在顶部，过渡态 900ms 一圈、运行态 3600ms 一圈（快慢区分进行中与已连接）
- 内圆：玻璃渐变底 + 主色图标（未运行 ⏻ / 运行中 ■），按压缩放至 0.94
- 过渡态图标切换为内圈转圈指示；`pending` 在点击瞬间置位，运行状态翻转或出现错误时立即结束，另有 20s 超时兜底
- 状态文案四态：未连接 / 连接中… / 已连接 / 正在断开…，过渡期不再显示「点击按钮进行连接」这类矛盾提示；底层报错以 InlineNotice 内联展示

### 其他
- 新增中英字符串各 10 条（connected / disconnected / connecting / disconnecting / tap_to_connect / tap_to_disconnect / current / switch / pick_title / pick_empty）
- 配色全部走 LocalPalette，未引入新色值，亮暗两套主题均已核对
